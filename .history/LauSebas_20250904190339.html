¿Que es Cloud?

Es un modelo que permite acceder a servicios de almacenamiento, procesamiento y aplicaciones a traves de internet.

¿Cuales son los modelos de entrega?

  • Nube publica
    • Ejemplos de proveedores: Amazon Web Services (AWS), Microsoft Azure
    • Casos: Alojar sitios web, APIs, bases de datos administradas
  • Nube privada
    • Ejemplos de proveedores: Stack Datacenter en una empresa
    • Casos: Infraestructura de TI interna, aplicaciones empresariales
