¿Que es Cloud?

Es un modelo que permite acceder a servicios de almacenamiento, procesamiento y aplicaciones a traves de internet.

¿Cuales son los modelos de entrega?

    Modelos de Nube: Ejemplos

    Nube pública

    Infraestructura propiedad y operación de un proveedor externo; recursos compartidos entre múltiples clientes.

    • Ejemplos de proveedores: Amazon Web Services (AWS), Microsoft Azure, Google Cloud Platform (GCP)
    • Casos típicos: alojar sitios web, APIs, bases de datos administradas, serverless

    Nube privada

    Infraestructura dedicada para una sola organización; puede estar on-premises o en un datacenter de un tercero.

    • Ejemplos de implementación: OpenStack en el datacenter de la empresa, VMware vSphere/Cloud Foundation, Red Hat OpenShift en infraestructura propia
    • Casos típicos: cargas con requisitos estrictos de seguridad, cumplimiento y personalización

    Nube híbrida

    Combinación de nube privada y pública con orquestación para mover datos y cargas entre ambas.

    • Ejemplos de soluciones: Azure Arc + Azure, AWS Outposts + AWS, Google Anthos + GCP
    • Casos típicos: burst de capacidad a la nube pública, DR/backup, modernización gradual

    Nube comunitaria

    Infraestructura compartida por organizaciones con requerimientos comunes (sector, regulación o misión).

    • Ejemplos: Microsoft 365 Government (GCC), Salesforce Government Cloud, consorcios académicos con OpenStack compartido
    • Casos típicos: entidades gubernamentales, salud, educación con políticas y controles comunes
