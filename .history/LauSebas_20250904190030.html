¿Que es Cloud?

Es un modelo que permite acceder a servicios de almacenamiento, procesamiento y aplicaciones a traves de internet.

¿Cuales son los modelos de entrega?

  • Nube publica
    • Ejemplos de proveedores: Amazon Web Services (AWS), Microsoft Azure, Google Cloud Platform (GCP)
    • Casos típicos: alojar sitios web, APIs, bases de datos administradas, serverless
  • Nube privada
  • nube Hibrida
  • nube Comunitaria
