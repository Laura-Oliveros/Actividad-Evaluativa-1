¿Que es Cloud?

Es un modelo que permite acceder a servicios de almacenamiento, procesamiento y aplicaciones a traves de internet.

¿Cuales son los modelos de entrega?

  • Nube publica
    • Ejemplos Amazon Web Services (AWS), Microsoft Azure
    • Casos: Alojar sitios web, APIs, bases de datos administradas
  • Nube privada
    • Ejemplos Stack Datacenter en una empresa
    • Casos: Infraestructura de TI interna, aplicaciones empresariales
  • nube Hibrida
    • Ejemplos Azure Arc + Azure
    • Casos: Capacidad a la nube pública, DR/backup
  • nube Comunitaria
    • Ejemplos:Consorcios académicos con OpenStack compartido
    • Casos: entidades gubernamentales, salud, educación con políticas

Explicación Comandos Git Utilizados

git init = Crear e inicializar repositorio
git add README.md = Añadir el README
git commit -m "TallerEvaluativo1" = Pasa el commit de tallerEvaluativo1, en la cual inserta una fila que seria el README mientras la creación del GIT
git branch -M main = Gestiona la rama de un repositorio en el cual se crea el main.
git remote add origin https: = Pasamos el Link de despligue o donde se encuentra el repositorio
git push -u origin main = Mandamos el push ósea las actualizaciones y archivos directo al main
git checkout main = Checkamos si estamos dentro del main
git checkout -b tallerEvaluativo11 = Ahora creamos la rama de tallerEvaluativo11
git push -u origin tallerEvaluativo11 = Y pues corremos todo para la rama, ósea que se gestione y se manden las actualizaciones
git status = Verificar en la rama que archivos se encuentran.
git add . = Añade todo para que se agregue al repositorio
git commit -m "Explicación y entrega De proovedores Cloud" = Enviamos el commit con un comentario
